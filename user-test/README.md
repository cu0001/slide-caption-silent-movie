# ユーザーテスト

はじめて使う人が、PDFから「字幕とカメラの動きが付いた無音の動画」ができるまでを試すための手順です。所要時間は15分ほどです。

テスト用のPDFは [coffee-break.pdf](coffee-break.pdf)（3ページ、コーヒーの休憩をテーマにしたスライド）です。`examples/` のサンプルは自動テストのたびに作り直されるため、ユーザーテストではこのフォルダのPDFを使ってください。このファイルは編集・上書きしないでください。

## 準備

1. 前提条件（リポジトリの [README](../README.md#前提条件)）をそろえる: Google Chrome、Node.js 22.13以降、npm。テストA では Claude Code も使います。
2. リポジトリのフォルダで依存パッケージを入れる。

   ```sh
   npm ci
   ```

3. 前回の結果が残っていれば消しておく（何度でもやり直せます）。

   ```sh
   rm -rf output/coffee-break
   ```

## テストA: AIアシスタントにPDFを渡す（主な使い方）

1. このリポジトリのフォルダで Claude Code を開く。
2. 次のどちらかで頼む。

   ```text
   /slide-caption-silent-movie user-test/coffee-break.pdf
   ```

   ```text
   user-test/coffee-break.pdf に字幕と動きを付けて動画にして
   ```

3. 完了の報告を待つ（数分）。途中でコマンド実行の許可を求められたら許可する。
4. `output/coffee-break/coffee-break-captions.webm` をChromeで開いて再生する（Chromeのウィンドウへドラッグ＆ドロップ）。

### 確認すること

| # | 確認すること | 期待する結果 |
|---|---|---|
| A1 | 動画ができたか | `output/coffee-break/` に `coffee-break-captions.webm` と `coffee-break-captions.json` がある |
| A2 | 長さ・音 | 3ページで25〜35秒ほど。音は出ない（音声トラックなし） |
| A3 | 字幕 | 各ページの下部に2〜4個。画面の見出しをそのまま繰り返さず、絵の内容（カップ、窓、メモなど）を説明している |
| A4 | 字幕の読みやすさ | 1つずつ最後まで読める速さで切り替わる。ふわっと出て消える |
| A5 | カメラの動き | ページごとに動きが違う（寄る・引く・横に流す・静止など）。寄る先が字幕で説明しているもの（カップ・窓・メモ）になっている |
| A6 | 動きの強さ | 落ち着いた速さで、酔うほど大きく動かない。字幕の帯に大事な絵が隠れない |
| A7 | 報告の内容 | アシスタントの報告に、ページごとの字幕・選んだ動きとその理由・合計時間・出力ファイルの場所がある |

## テストB: アプリで確認・手直しする

1. 開発サーバーを起動し、表示されたアドレス（`http://127.0.0.1:5173` など）をChromeで開く。

   ```sh
   npm run dev
   ```

2. 右上の「開く」で `output/coffee-break/coffee-break-captions.json` を読み込み、プレビューの ▶ で再生する。
3. スライドの一覧でスライドを選び、右側の字幕欄で字幕の文を1つ書き換え、「確認」で表示を見る。画面で直せるのは字幕だけです（動きはAIアシスタントに頼んで直します）。
4. 「保存」でプロジェクトを保存し、「WebMを書き出す」で動画を保存して、書き換えた内容が入っていることを確かめる。
5. （任意）「まとめて書き直す」に1行1つずつ入力して「字幕を作る（時間を自動で割り当て）」を押し、時間が自動で割り当て直されることを見る。

### 確認すること

| # | 確認すること | 期待する結果 |
|---|---|---|
| B1 | 読み込み | テストA の動画と同じ字幕・動きで再生される |
| B2 | 字幕の手直し | 書き換えた文がプレビューにすぐ反映される |
| B3 | 動きの手直し | 画面に動きの欄はなく、AIアシスタントに頼むと直った動きがプレビューに出る |
| B4 | 書き出し | 書き出した動画に手直しが入っている。音声トラックはない |
