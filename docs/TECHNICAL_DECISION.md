# 技術選定

Canvasで描画・プレビューし、WebCodecsのVP8/OpusとMediabunnyでWebMを生成します。Remotion、HyperFrames、FFmpegは依存関係に含みません。MPEGコーデックを使わないため、MP4出力とMP3/AAC入力はありません。WAV入力は独自に読み取ります。

判断の根拠・公式資料・確認範囲は [CODEC_POLICY.md](CODEC_POLICY.md)、配布対応は [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) を参照してください。

- **PDF**: Apache-2.0のPDF.jsでページを画像化し、MITのpdf-libで画像ベースのPDFを生成します。PDFページには決定的なカメラ移動を付けます。
- **要素ごとの動き**: 文字・画像・図形の要素ごとに開始時刻・表示時間・登場・表示中・退場の動きを持ち、各フレームの変形・透明度を要素データから決定的に計算します。登場は解析解の減衰ばねで計算します。
- **字幕**: 各スライドの字幕を、プレビューと書き出しで共通の描画関数によりフレームに描き込みます。無音で見られる動画を前提にしています。
- **AIアシスタントによる字幕**: 字幕の文章はAIアシスタントがスライドの静止画と文字を見て書き、`captions:apply` が読む速さで時間を割り当てます。アプリ自体は外部サービスやAPIキーを使いません。

プレビュー・WebM書き出し・PDF保存はすべて同じ描画関数を通るため、画面で見た動きと書き出した動画が一致します。サンプルの要素は元の文字・SVGから再構成したもので、PDFからの自動要素復元をうたうものではありません。
