# PDFから、字幕と動き付きの無音動画を作る

**PDF資料をAIアシスタントに渡して、説明字幕とアニメーション付きの動画を作るツールです。**

作った動画はブラウザで確認でき、字幕を直して保存できます。

![左に同梱のサンプルPDFのページ、右にそこから作った動画を並べたアニメーション。各ページのイラストや見出しが順番に現れ、字幕が切り替わる](docs/images/pdf-to-video.gif)

**IBM Bob・Claude Codeなど、ローカルのファイルを読み書きし、コマンドを実行できるAIアシスタントで利用できます。** IBM Bobで始める方は「[IBM Bobで使う](#ibm-bobで使う)」をご覧ください。

- **PDF全体を1本の動画に** — 見出しやイラストに、説明に合わせた動きを付けます。
- **音を出さずに見られる字幕付き** — ナレーションを付けずに作れます。
- **字幕は画面で手直し** — 文や表示時間を変更し、動画を書き出せます。
- **完成動画はWebM形式** — Google Chromeで再生できます。MP4出力には対応していません。

まず動きを見たい方は「デモで試す」へ。自分の資料を使う方は、その後の「自分のPDFを動画にする」へ進んでください。

[デモで試す](#デモで試す) · [IBM Bobで使う](#ibm-bobで使う) · [自分のPDFを動画にする](#自分のpdfを動画にする) · [困ったとき](#困ったとき) · [詳しい使い方](docs/REFERENCE.md)

## 前提条件

デモの再生・字幕の編集・動画の書き出しには、次のものを用意してください。

| 必要なもの | 目安 |
|---|---|
| Google Chrome | 最新版。アプリを開くブラウザに使います |
| Node.js と npm | Node.js 22.13以降の22系、または24系。npmはNode.jsに付属します |

自分のPDFから字幕と動きを作るときは、さらに **IBM Bob・Claude CodeなどのAIアシスタント** が必要です。ローカルの画像やファイルを読み取り、JSONを書き込み、コマンドを実行できるものを使います。画像を確認できるモデル・ツールを利用してください。

**デモを試すだけなら、AIアシスタントの準備は不要です。** アプリにAPIキーを設定する必要はありません。初回のパッケージのインストールにはインターネット接続が必要です。AIアシスタントの利用環境・接続・料金は、利用するサービスに従います。

## デモで試す

### 1. プロジェクトをダウンロードする

このGitHubページの **Code → Download ZIP** からダウンロードし、ZIPを展開します。すでに手元にフォルダーがある場合は、そのフォルダーを使ってください。

### 2. アプリを起動する

ターミナル（コマンドを入力するアプリ）で、展開したフォルダーへ移動します。Macでは `cd ` と入力し、フォルダーをターミナルへドラッグしてEnterを押すと移動できます。Windowsでは、展開したフォルダーをエクスプローラーで開き、アドレス欄に `powershell` と入力してEnterを押す方法もあります。

次のコマンドを、1行ずつ実行してください。

```sh
npm ci
npm run dev
```

- `npm ci` は、必要な部品をインストールします。初回に実行します。実行前に影響を確認したい方は「[npm ciで起きることとリスク](#npm-ciで起きることとリスク)」をご覧ください。
- `npm run dev` は、アプリを起動します。次回からはこちらだけで起動できます。

ブラウザが自動で開きます。Chrome以外が開いた場合は、ターミナルに表示されたアドレスをChromeで開いてください。起動中はターミナルを開いたままにします。

### 3. デモを開いて、動画にしてみる

Chromeのアドレスの末尾に **`/?sample=demo`** を付けます。

例：`http://127.0.0.1:5173/?sample=demo`（ポート番号は、起動時に表示されたものに合わせてください）

画像の番号は、下の手順の番号と対応しています。

![デモを開いたアプリの画面。再生ボタン、まとめて書き直す、字幕を作る、確認、保存、WebMを書き出すの位置に手順の番号を付けている](docs/images/demo-steps.png)

1. **▶** を押して、3枚・約12秒のデモを再生します。この組み込みデモには、確認用の音が入っています。
2. 右側の **「まとめて書き直す」** に、試しの字幕を1行入力します。
3. **「字幕を作る（時間を自動で割り当て）」** を押し、**「確認」** で表示を見ます。
4. **「保存」** で編集用データを保存します。
5. **「WebMを書き出す」** を押して、動画ファイルを保存します。

終了するときは、ターミナルで **Control + C** を押してください。

## IBM Bobで使う

IBM Bobでこのプロジェクトのフォルダーを開き、同じPCにNode.js・npm・Google Chromeを用意します。Bobは制作のためのファイル操作とコマンド実行を担当し、アプリの再生・編集・動画の書き出しはChromeで行います。Bob専用のパッケージや、アプリへのAPIキー設定は不要です。

### 1. フォルダーを開いて起動する

1. IBM Bobで、`README.md` と `package.json` が入っているフォルダーを開きます。
2. Bobのターミナルで `node -v` と `npm -v` を実行し、前提条件を満たしているか確認します。
3. 初回は `npm ci` を実行し、続けて `npm run dev` を実行します。
4. 表示されたURLをChromeで開きます。デモはURLの末尾に `/?sample=demo` を付けると表示されます。

PDFから動画を作るときは、Bobのチャットを **Agentモード** にします。Askモードは読み取り専用です。操作方法は [IBM Bob公式クイックスタート](https://bob.ibm.com/docs/ide/getting-started/quickstart) を参照してください。ファイル変更やコマンド実行の承認が表示されたら、対象と内容を確認して進めます。

### 2. Bobに制作を依頼する

次の依頼文を、そのままBobのチャットに貼り付けてください。自分の資料を使う場合は、PDFのパスを置き換えます。

```text
user-test/coffee-break.pdf を説明字幕付きの無音動画にしてください。動きはなるべく多めにしてください。
```

### Bobでの制作手順の読み替え

制作手順書は `.claude/skills/` にありますが、中で使うnpmコマンドはこのプロジェクト共通のものです。**Bobは `.claude/skills/` の手順書を標準で読み取れるので、依頼文でパスを指定する必要はありません。**

| 手順書の記載 | IBM Bobでの進め方 |
|---|---|
| `Read` でPDF・画像を見る | Bobで利用できるPDF・画像の読み取り機能で内容を確認します。PDFを直接読めない場合は、`captions:export` のページ画像と、必要に応じてPDFから抽出した本文を使います |
| `Bash` でnpmコマンドを実行する | Bobのターミナル・コマンド実行機能を使います。Windowsでも記載のnpmコマンドを使えます |
| `.claude/launch.json`・`preview_start`・`mcp__Claude_Browser__*` | Bobのターミナルで `npm run dev` を起動し、表示されたURLをChromeで開きます |
| `run_in_background` | 開発サーバー用のターミナルを開いたままにし、制作コマンドは別のターミナルで実行します |
| 専用の通知ツール | 利用できない場合は、Bobのチャットで完了・失敗と保存先を報告します |

画像を読み取れない環境では、部品の位置や字幕の内容を十分に確認できません。画像を確認できる環境に切り替えてから制作してください。また、CLIはPlaywright経由で**インストール済みのGoogle Chrome**を起動します。Chromeを起動できるローカル環境で実行してください。

### Bobに動きの修正を頼む

画面で字幕を編集した場合は、先に「保存」で最新のJSONを保存し、そのファイルを指定します。

```text
output/coffee-break/coffee-break-captions.json の、2枚目の太陽をもう少しゆっくり登場させてください。
起動時のプロジェクトを更新して、WebMも書き出し直してください。
```

ここで説明するBob向け手順は、既存のnpmコマンドを利用する方法です。IBM Bob上での一連の操作は未検証のため、利用するバージョン・モデル・実行権限によって操作が異なる場合があります。

## 自分のPDFを動画にする

**PDFの取り込みと動画の組み立ては、AIアシスタントに頼みます。** ブラウザの「開く」は、作成済みのプロジェクト（JSON）を読み込むボタンです。

### 1. PDFを用意する

PDFをプロジェクトのフォルダーに置きます。**40MB・60ページ以内、パスワードなし**のPDFが対象です。

まずは、同梱の **`user-test/coffee-break.pdf`**（3ページ）で試せます。自分の資料を使うときは、以下の依頼文のPDFのパスを置き換えてください。

### 2. AIアシスタントに頼む

IBM Bob・Claude Codeなどで、このプロジェクトのフォルダーを開きます。IBM Bobでは、上記の「[IBM Bobで使う](#ibm-bobで使う)」の依頼文を使ってください。まだ `npm ci` を実行していなければ、先に実行してください。

次のように依頼します。

```text
user-test/coffee-break.pdf を説明字幕付きの無音動画にしてください。動きはなるべく多めにしてください。
```

Claude Codeでは、次の指定でも依頼できます。

```text
/slide-caption-silent-movie user-test/coffee-break.pdf 動きはなるべく多めに
```

アシスタントが、ページの確認 → 字幕と動きの作成 → 動画の書き出しを進めます。ページ数や内容によって、数分以上かかることがあります。

### 3. 完成したファイルを開く

コーヒーのサンプルでは、次の場所に保存されます。

| ファイル | 使い方 |
|---|---|
| `output/coffee-break/coffee-break-captions.webm` | 完成動画。Chromeへドラッグすると再生できます |
| `output/coffee-break/coffee-break-captions.json` | 編集用データ。アプリの「開く」で読み込みます |

保存先は、アシスタントの完了報告でも確認できます。自分のPDFの場合は、PDFの名前に応じたフォルダーになります。

**動画を見るならWebM、あとで字幕を直すならJSON。** JSONも一緒に残しておくと、後から編集できます。

## 字幕を直して保存する

画像の番号は、下の手順の番号と対応しています。

![サンプルのプロジェクトを開いたアプリの画面。開く、次へ、スライド一覧、字幕の欄、保存、WebMを書き出すの位置に手順の番号を付けている](docs/images/caption-editing.png)

1. `npm run dev` でアプリを起動し、Chromeで開きます。
2. **「開く」** で、編集したいJSONを読み込みます。
3. **「前へ」「次へ」** やスライド一覧で、直したいページを選びます。
4. 右側で字幕の文・開始時刻・表示秒数を直し、**「確認」** で表示を見ます。
5. **「保存」** で編集後のJSONを保存します。**自動保存はありません。**
6. **「WebMを書き出す」** で、修正を反映した動画を保存します。

複数の字幕を作り直す場合は、「まとめて書き直す」に1行1つずつ入力してください。読む速さに合わせて表示時間を割り当て、必要ならスライドの時間を伸ばします。

各字幕の下の「分ける」「下とつなぐ」「下に追加」で、字幕を分けたり足したりできます。間違えたときは、ヘッダーの矢印（`⌘Z` / `Ctrl+Z`）で元に戻せます。キー操作などの一覧は「[画面でできること](docs/REFERENCE.md#画面でできること)」にあります。

画面で変更できるのは字幕の文と時間です。動きを直すときは、対象のJSONを示してAIアシスタントに頼みます。画面で字幕を編集した場合は、保存した最新のJSONを渡してください。

```text
2枚目の太陽を、もう少しゆっくり登場させてください。
```

## 困ったとき

| 状況 | 対処 |
|---|---|
| `npm` が見つからない | Node.jsをインストールし、ターミナルを開き直してください。`node -v` と `npm -v` で確認できます |
| `package.json` が見つからない | コマンドを実行する場所を確認してください。READMEと `package.json` が入っているフォルダーで実行します |
| Bobが説明だけしてファイルを作らない | Agentモードに切り替え、ファイル変更・コマンド実行の承認待ちがないか確認してください |
| AIアシスタントが手順書を使わずに進める | 依頼文の先頭に「`.claude/skills/slide-caption-silent-movie/SKILL.md` の手順で、」と加えてください |
| `Google Chrome` が見つからないというエラーになる | 同じPCにGoogle Chromeをインストールしてください。CLIはPlaywrightの `channel: 'chrome'` で起動するため、別のブラウザだけでは実行できません |
| 「起動時のプロジェクトがありません」と出る | 初回は正常です。アドレス末尾に `/?sample=demo` を付けるか、「開く」でJSONを読み込んでください |
| ブラウザが開かない・再接続できない | ターミナルで `npm run dev` が動いているか確認し、そこに表示されたアドレスをChromeで開いてください |
| `/?sample=coffee` などのサンプルが開けない | 組み込みデモは準備不要です。それ以外のサンプルは `npm run samples:prepare` で生成します（ChromeとPython 3が必要です） |
| PDFを「開く」で選べない | PDFはAIアシスタントに渡します。「開く」で選ぶのは編集用のJSONです |
| 保存・書き出しができない | 空の字幕や、字幕の表示時間の重なりなど、画面に表示された警告を修正してください |
| ブラウザが非対応と表示される | 最新版Chromeを使い、ターミナルに表示された `http://127.0.0.1:…` のアドレスで開いてください |
| 長い動画の書き出しに時間がかかる | 完了を待ってください。端末のメモリや空き容量が必要です。画面の進捗とエラー表示も確認してください |

## npm ciで起きることとリスク

`npm ci` は、`package-lock.json` に記録された版の部品を、このプロジェクトの `node_modules` フォルダーへインストールするコマンドです。

### 起きること

- 既存の `node_modules` を削除して作り直します。PDFや `output/` など、ほかのファイルは変更しません。
- npmの公開サービス（`registry.npmjs.org`）から部品をダウンロードします。macOS（Apple Silicon）では38個・約170MBです。OSによって、入る部品は変わります。
- `package.json` と `package-lock.json` は書き換えません。2つの内容が食い違っている場合は、インストールせずにエラーで止まります。
- インストール先はこのフォルダーの中だけです。PC全体への導入や、Google Chromeのダウンロードは行いません。

### リスクと対処

| リスク | 内容 | 対処 |
|---|---|---|
| 第三者のプログラムが入る | 部品は、`npm run dev` などで実行すると自分のユーザー権限で動き、PC内のファイルやネットワークを扱えます。`npm ci` のハッシュ照合で分かるのは、記録時と同じ内容かどうかだけで、安全性の保証ではありません | 機密情報を扱うPCでは、所属組織のルールに従って実行するか、業務データのない環境で試してください |
| 中身を読みにくい部品がある | 動画のビルドなどに使う部品の一部は、コンパイル済みのプログラム（`.node`）です | 上と同じです |
| 入手元が違うコピーを使う | フォルダーの中身が改変されていると、`package-lock.json` やコマンドの定義も信頼できません | 正規のGitHubページからダウンロードしてください |
| 後から脆弱性が見つかる | 版を固定しているため、部品に問題が見つかっても自動では更新されません。2026年11月9日時点の `npm audit` では0件です | ときどき `npm audit` で確認してください。脆弱性が報告された場合は、結果をお手持ちのAIアシスタントに見せて、影響と対処を相談してください |
| `node_modules` の変更が消える | 中身を手で変更していた場合、その変更は元に戻せません | 通常の利用では `node_modules` を変更しないでください |
| 通信や容量の不足で失敗する | インターネット接続と空き容量が必要です。社内ネットワークでは接続が制限されている場合があります | 原因を解消して、もう一度 `npm ci` を実行してください |

現在の部品には、インストール中に独自の処理を実行するスクリプトの定義はありません。新しいnpmでは `fsevents` について `install scripts` の警告が表示されることがありますが、これが表示されてもインストールは完了します。

## 対応する資料と出力形式

| 項目 | 対応範囲 |
|---|---|
| 入力PDF | 40MB・60ページ以内、パスワードなし |
| 字幕 | 1スライド20個まで、1個120文字・手動改行を含め12行以内 |
| 動画の長さ | 1スライド1〜60秒、全体60分以内 |
| 完成動画 | WebM形式、1280×720、30fps。映像はVP8、音声付きはOpus |
| 音声入力 | 非圧縮WAVのみ。30MB・10分以内。通常のPDFからの作成では音声を付けません |

長い動画の書き出しには、時間とメモリ・空き容量が必要です。写真やグラデーションの上にある物など、切り分けが難しいページは、ページ全体に寄る・引くなどの動きを付けます。
